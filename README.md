# Deque Implementation (CS 61B Project 1)

This project is part of the UC Berkeley CS 61B course on Data Structures and Algorithms. It involves implementing two versions of a **double-ended queue (deque)**: one using an array and the other using a doubly linked list.

## Features
- **ArrayDeque**:
  - Resizable array-based implementation with dynamic resizing.
  - Constant time operations for adding/removing elements from both ends.
- **LinkedListDeque**:
  - Doubly linked list implementation with nodes pointing to previous and next elements.
  - Efficient operations for all deque functionality.
- **Generic Implementation**:
  - Supports any data type through the use of generics.
- **Iterator Support**:
  - Fully iterable using custom iterator implementation.
- **Thorough Testing**:
  - Rigorous edge-case testing with JUnit for correctness.
